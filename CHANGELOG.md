### Added

- Initial official SDK surface for all 28 LTESocks Public API v2 operations and 13 component schemas.
- Bearer authentication, configurable transport, timeouts, localization, and a raw request escape hatch.
- Typed resources for user, ports, payments, and general catalog operations.
- Automatic idempotency UUIDs with bounded retries only for transport failures without an HTTP response.
- Normalized errors with headers, raw bodies, retry timing, and idempotency metadata.
- Response metadata helpers, pagination support, VPN ZIP downloads, and webhook signature verification.
- Reproducible OpenAPI generation, tests, CI, release safeguards, documentation, and package validation.
